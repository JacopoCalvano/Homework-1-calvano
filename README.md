Homework 1 - Algorithmic Methods of Data Mining

Solutions for Homework 1 of Algorithmic Methods of Data Mining (Sc.M. in Data Science, Sapienza University of Rome, 2026-2027).

Problem 1 is a set of Python challenges on HackerRank, covering the basics, strings, sets, collections, dates, regular expressions, XML, decorators and NumPy. Problem 2 is six short algorithm exercises, also on HackerRank.
The code is in scripts.py, with one section per challenge. The same solutions are also saved as single files in solutions/. The code is exactly as I submitted it on HackerRank.

submissions.pdf is the list of my HackerRank submissions. printouts/ contains screenshots of the accepted submissions, and printouts/SUBMISSIONS_INDEX.md lists the submission used for each challenge.
